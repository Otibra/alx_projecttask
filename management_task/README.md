# Task Management Backend

## Description

This project is a backend task management system built using the Django framework. It provides the server-side logic required to create, manage, update, and delete tasks while storing them in a database.

## Purpose

The goal of this project is to demonstrate backend development concepts such as API design, database management, and CRUD operations using Django.

## Features

* Create tasks
* Retrieve tasks from the database
* Update existing tasks
* Delete tasks
* Store task data using a database

## How It Works

The backend handles requests related to task management. When a request is sent to the server, Django processes the request through views, interacts with the database through models, and returns the appropriate response.

## Technologies Used

* Python
* Django
* SQLite
* REST principles
